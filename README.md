# 企业知识库 Agentic RAG 智能问答系统

## 项目概述

面向企业知识库问答场景，基于 LangGraph 设计 Agent 工作流，并在云端轻量化为自定义 Agent Loop。系统覆盖文档接入、向量检索、工具调用、答案生成、会话记忆、安全防护和评测闭环。

## 核心能力

- **Agent 工作流**：支持知识库检索、数学计算、联网搜索 3 类工具，限制最多 3 步执行，避免无效循环。
- **RAG 检索**：使用 BGE-small-zh-v1.5 与 ChromaDB，采用 600 字符分片、120 字符重叠、余弦阈值 0.55 和轻量关键词重排。
- **安全防护**：JWT + bcrypt 认证、部门权限控制、提示词注入检测、`<UNTRUSTED_DATA>` 数据隔离和敏感信息拦截。
- **会话与可观测性**：SQLite 持久化最近 4 轮上下文，用户级缓存 TTL 10 分钟；通过 Trace ID 记录规划、检索、工具调用和模型生成耗时。
- **流式与测试网站**：基于 SSE 返回规划状态、检索来源和生成内容；配套 Web 测试网站支持登录、问答、Markdown 上传、入库进度、历史记录、Trace 日志、系统状态和反馈。
- **低成本部署**：Docker 部署到 2 核 2G 云主机，数据卷持久化 SQLite、ChromaDB 和模型文件，容器内存限制 1800MB。

## 已验证结果

- 计算路由准确率：100%（10/10）
- 会话记忆通过率：100%（5/5）
- 重复问题缓存命中率：100%（5/5）
- Agent 最大执行步数：3 步
- 云端健康检查：HTTP 200
- SSE 登录、问答与 `chunk/done/complete` 事件链路已验证

## 技术栈

Python、LangGraph（工作流设计）、FastAPI、DeepSeek API、BGE-small-zh-v1.5、ChromaDB、SQLite、SSE、JWT、bcrypt、HTML/JavaScript、Docker
